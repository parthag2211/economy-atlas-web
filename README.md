# Economy Atlas deployment

Compiled assets and an AES-GCM encrypted research snapshot for a personal research workspace. The private source repository holds the canonical dataset and provenance. A private access key is required to read the snapshot.

Browser edits stay encrypted in that browser. Export a backup to preserve edits across devices. Dataset coverage includes historical inventories and requires source-specific verification.

Open-source license notices are in THIRD_PARTY_NOTICES.txt. The Natural Earth basemap is public domain.
